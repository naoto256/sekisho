# Guides

Complete, runnable setups. Each one starts from a fresh install and ends
with a working protected route. The [documentation](../docs/) is the
reference; these are the worked examples.

- **[Grafana behind Entra ID (SAML)](grafana-entra-saml.html)** —
  the common enterprise case. Group-based policy, signed identity, and
  turning off Grafana's own login.
- **[An appliance UI that will never support SSO](legacy-appliance.html)** —
  a box with a fixed web interface, basic auth, and an IP in its redirects.
  Put it behind the checkpoint without touching it.
